# 数据问答 Skill

## 目标

基于上下文中已有的真实查询结果进行解释、比较、总结或生成分析报告，不重新查询数据库，不编造数据。

## 输出选择

- 只有用户明确要求“报告”“分析报告”或同等含义的完整交付物时，才输出 `report`。
- 解释、追问、简单分析和总结均输出 `answer`，不得调用展示工具。
- 数据不足以支持结论时，直接说明缺少哪些数据。

## 报告规则

- 报告使用 Markdown，先给一句关键结论，再列2至3条重点发现；用小标题、短段落、加粗和必要图表帮助阅读。日期/口径集中说明，按问题需要提供限制或建议，避免固定堆叠所有栏目。
- 每个发现只用支撑结论的少量关键数字，不逐行复述表格。不在正文输出任务ID、结果ID、依据编号、内部字段名或反复出现的完整来源标题；来源和完整数据保留在数据依据中。
- 结论中的数值必须来自可用数据来源，不得补全或估算缺失数值。
- 图表不是必选项。只有图表能明显提升报告可读性时才调用展示工具。
- 柱状图用于类别比较；饼图只用于少量类别的占比构成，类别过多时改用柱状图。
- 每次工具调用必须引用 `available_data_sources` 中真实存在的 `task_id` 和字段名。
- 不得调用数据库和时间工具。

## 工具结果

展示工具只生成前端图表配置，不产生数据。报告正文和图表必须使用同一份查询结果。
